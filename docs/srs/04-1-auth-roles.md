### 4.1 Authentication & Roles

**Description:** This feature lets users register and log in with an email address and password, and restricts every function to the user's role (Citizen, Collection Vehicle Driver, Admin / Municipal Officer, Disposal Facility Operator). It also lets the Admin create and deactivate Driver and Operator accounts. It is provided by the Auth & User Service.

| Req ID | Requirement (The system shall…) | Type | Priority | Source/Stakeholder | Acceptance criteria / Test case ref | Comments / Dependencies |
|---|---|---|---|---|---|---|
| SCW-F-001 | The system shall allow a user to register with a unique email address and a password of at least 8 characters, and to log in with that email and password; on successful login the system shall issue a JWT access token containing the user's role (Citizen, Driver, Admin or Operator). Self-registration shall create Citizen accounts only. | Functional | High | Citizen, Admin | AC-SCW-F-001: A registered user with valid credentials receives HTTP 200 and a JWT whose role claim matches the account role; an invalid email/password combination returns HTTP 401 with error code `INVALID_CREDENTIALS` and no token; registering an email that already exists returns HTTP 409. Test: TC-AUTH-01 | Depends on SCW-SEC-001 (bcrypt hashing), SCW-SEC-002 (30-minute token expiry), SCW-SEC-005 (lockout after 5 failed logins). |
| SCW-F-002 | The system shall restrict each user to the features and API endpoints of their role, show each role only its own menu items in the Web Frontend, and return HTTP 403 with error code `FORBIDDEN` when a user calls an endpoint not permitted for their role. | Functional | High | Admin, all users | AC-SCW-F-002: A Citizen token calling an Admin-only endpoint (e.g. `POST /api/v1/routes/generate`) receives HTTP 403 with error code `FORBIDDEN` in 100% of attempts, and the Citizen's menu shows no Admin, Driver or Operator items. Test: TC-AUTH-02 | Role checks enforced on the server for every API call (SCW-SEC-004); hiding menu items alone is not sufficient. |
| SCW-F-003 | The system shall allow an Admin to create Driver and Operator accounts (name, email, role, temporary password) and to deactivate any non-Admin account; a deactivated account shall not be able to log in, and its existing tokens shall be rejected. | Functional | Medium | Admin / Municipal Officer | AC-SCW-F-003: An account created by the Admin can log in with the assigned role; after deactivation, a login attempt returns HTTP 401 and any API call with the account's previously issued token returns HTTP 401 within 1 minute. Test: covered in sprint testing | Only Admins can create Driver/Operator accounts. Account changes are written to the audit log (SCW-SEC-006). Drivers are linked to vehicles by SCW-F-022. |
