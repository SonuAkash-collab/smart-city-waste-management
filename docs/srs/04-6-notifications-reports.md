### 4.6 Notifications & Reports

**Description:** This feature keeps citizens informed of every change in their request status, gives the Admin a dashboard of current operations, and lets the Admin export a daily collection report. It is provided by the Notification & Reporting Service.

| Req ID | Requirement (The system shall…) | Type | Priority | Source/Stakeholder | Acceptance criteria / Test case ref | Comments / Dependencies |
|---|---|---|---|---|---|---|
| SCW-F-050 | The system shall notify the citizen who owns a collection request, by an in-app notification and an email, each time the request's status changes (Submitted, Approved, Scheduled, Collected, Rejected, Missed or Cancelled); each notification shall state the request ID, the new status and the time of the change. | Functional | High | Citizen | AC-SCW-F-050: For every status change of a request, exactly one in-app notification appears in the owner's notification list within 1 minute, and one email is handed to the email provider within 5 minutes; both contain the request ID, new status and timestamp. Test: TC-NOT-01 | Triggered by status changes from the Request Service (SCW-F-012, SCW-F-013, SCW-F-014) and the Route Optimization Engine (SCW-F-040, SCW-F-044). If the email provider is unavailable, the in-app notification is still created and the email is retried. |
| SCW-F-051 | The system shall provide an Admin dashboard showing (a) the number of requests in each status, with pending (Submitted) requests listed by priority, (b) the number of vehicles in each status (Available, On Route, Maintenance), and (c) each facility's remaining capacity in kg and as a percentage of daily capacity. | Functional | Medium | Admin / Municipal Officer | AC-SCW-F-051: The dashboard loads within 2 s for an Admin user, and every count and capacity figure matches the database at the time of loading (verified against direct database queries for a test data set). Test: covered in sprint testing | Reads data from the Request Service, Fleet Service and Facility Service. Admin role only (SCW-F-002). |
| SCW-F-052 | The system shall allow an Admin to export, for a selected date, a CSV collection report with one row per route stop containing: date, route ID, vehicle registration number, driver name, request ID, waste type, quantity (kg), stop status (Collected/Missed) and facility ID for facility visits. | Functional | Medium | Admin / Municipal Officer | AC-SCW-F-052: Exporting the report for a date with N route stops downloads a UTF-8 CSV file with a header row and exactly N data rows, whose values match the stored route data; export completes within 5 s for up to 1,000 stops. Test: covered in sprint testing | Depends on route data from SCW-F-040 and SCW-F-044. Admin role only (SCW-F-002). |
