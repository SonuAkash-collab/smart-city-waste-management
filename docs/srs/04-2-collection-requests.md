### 4.2 Collection Requests

**Description:** This feature lets Citizens submit, track and cancel collection requests, and lets the Admin / Municipal Officer view, filter, approve and reject them. The Request Service validates and manages request data and assigns request priority; the Web Frontend provides the role-specific interfaces. Request Service APIs use the `/api/v1` base path and JSON, with the agreed request endpoints: `POST /requests`, `GET /requests`, `GET /requests/{id}`, `PATCH /requests/{id}/status` and `DELETE /requests/{id}` (cancel).
