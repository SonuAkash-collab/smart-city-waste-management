# User guide

Open the app (for example http://localhost:8000) and log in. The menu only shows the pages for your role.

## Citizen
1. **Register** with your name, email and a password of 8+ characters.
2. **Request pickup**: tap the map where the waste is (or type an address and press *Find*, or *Use my location*), choose the waste type, enter the weight and optionally add a photo. You see the request number and its priority.
3. **My requests**: follow each request (Submitted → Approved → Scheduled → Collected). You can cancel while it is Submitted or Approved. *Details* shows the date it is planned for.
4. **Notifications**: every status change appears here and is also emailed.

## Admin / Municipal Officer
* **Dashboard**: requests by status, pending requests by priority, vehicles by status, facility capacity; download the daily CSV report.
* **Requests**: filter by status, priority, waste type and date; approve or reject, optionally change the priority.
* **Routes**: pick a date and press *Generate routes*. Alerts tell you about loads no facility can take and requests that could not be planned.
* **Vehicles**: add vehicles, set Available or Maintenance, assign one driver per vehicle.
* **Facilities**: add facilities and watch today's remaining capacity.
* **Staff**: create driver and operator accounts with a temporary password, or deactivate them.

## Driver
* **My route**: your stops in order on a map. Mark each pickup *Collected* or *Missed* and each facility stop *Unloaded*. *Directions* opens OpenStreetMap.

## Facility Operator
* **Record delivery**: choose the facility, the vehicle, the waste type and the weight. Deliveries above today's remaining capacity, of a type the facility does not take, or from an unknown vehicle are refused.
